# OpenHeart

A cheap, efficient "heartbeat" sensor that detects movement using low-frequency
radio waves.

## Thesis

Most vital-sign and presence sensors are expensive, power-hungry, or require
contact with the body. OpenHeart takes a different approach: it emits
low-frequency radio waves and measures how reflected signals change over time.
Because even small movements — a heartbeat, breathing, a person shifting in a
room — perturb these reflections, the device can detect motion without any
physical contact, cameras, or costly components.

The goal is a sensor that is:

- **Cheap** — built from inexpensive, widely available parts.
- **Efficient** — low power draw suited for always-on operation.
- **Contactless** — senses movement through radio reflection, not direct contact.
